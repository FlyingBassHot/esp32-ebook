# ESP32-S3 桌面智能终端（天气站 · AI 助手 · 电子书阅读器）

> 基于 [78/xiaozhi-esp32](https://github.com/78/xiaozhi-esp32)（v2.2.2）二次开发，
> 目标硬件：**微雪 ESP32-S3-RLCD-4.2** 开发板（400×300 反射式单色屏）。
>
> 原项目说明文档见 [README_zh.md](README_zh.md) / [README_ja.md](README_ja.md)。

本项目在小智 AI 语音助手的基础上，把设备改造为一台桌面智能终端：
**五页循环 UI**（天气时钟 / 音乐播放 / 番茄钟 / 电子书阅读 / 系统信息）、备忘录、白噪音，
并保留完整的语音对话能力。对话状态通过顶栏中央的「小智」状态图标表达（AI 对话卡已全部移除）。

## 按键映射使用说明

设备共两个实体按键：**BOOT**（GPIO0，板上标注 BOOT）与 **USER**（GPIO18）。

### 全局操作（任意页面生效）

| 按键 | 操作 | 功能 |
|---|---|---|
| BOOT | **单击** | 唤醒 / 停止 AI 语音对话 |
| BOOT | **单击**（开机启动时） | 进入配网模式（首次使用配置 WiFi） |
| BOOT | **长按** | 未注册（防误触） |
| USER | **单击** | 切换页面（阅读页例外，见下） |
| BOOT | **双击** | 按页面执行对应动作（见下表） |
| USER | **双击 / 长按** | 按页面执行对应动作（见下表） |

### 页面切换顺序

USER 单击按以下顺序循环：

```
天气页 → 音乐页 → 番茄钟页 → 阅读页 → 系统信息页 → 天气页 …
```

### 各页面按键功能

| 页面 | BOOT 双击 | USER 单击 | USER 双击 | USER 长按 |
|---|---|---|---|---|
| 🌤 **天气页** | 刷新数据（NTP 时间同步） | 切到音乐页 | 刷新数据 | 预留 |
| 🎵 **音乐页** | 停止播放 | 切到番茄钟页 | 音量 **+10%** | 音量 **−10%** |
| 🍅 **番茄钟页** | 暂停 / 继续 | 切到阅读页 | 开始（25 分钟）/ 停止 | 预留 |
| 📖 **阅读页** | **退出阅读**（切到系统信息页） | **下一页**（章末自动进下一章） | 上一章 | 下一章 |
| ℹ️ **系统信息页** | 切回天气页 | 切回天气页 | 预留 | 预留 |

### 使用要点

- **音量调节**：音乐页双击/长按 USER 调节输出音量（0~100%，步进 10%），
  屏幕中央会短暂显示「音量 xx%」胶囊（2 秒后自动消失）。调节即时生效，重启后保持。
- **阅读操作**：进入阅读页后没有顶栏，沉浸阅读；USER 单击翻页，双击/长按切章，
  BOOT 双击随时退出。语音说「打开阅读页」「看书」也可进入。
- **番茄钟**：BOOT 双击暂停/继续，USER 双击开始或停止（默认 25 分钟，带白噪音）；
  也可用语音「开始番茄钟 / 暂停番茄钟 / 停止番茄钟」。
- **刷新数据**：天气页双击任意键重新同步 NTP 时间（修正时钟漂移）。
- **语音切页**：任意页面说「切到音乐页 / 打开系统信息页 / 切换屏幕」等，
  对应 MCP 工具 `self.disp.switch`（`toggle`/`weather`/`music`/`pomodoro`/`reader`/`system`）。

### 顶栏状态图标（天气 / 音乐 / 番茄钟 / 系统信息页）

顶栏正中显示「小智」+ 状态图标，代替原 AI 对话卡：

| 图标 | 状态 |
|---|---|
| ○ 空心圆 | 待命 |
| ◎ 同心圆（脉冲） | 聆听 / 连接中 |
| ● 实心圆（两侧声波交替） | 说话中 |

阅读页为沉浸模式，无顶栏与状态图标。

## 在原项目基础上新增了什么

### 1. 板级支持（全新目录 `main/boards/waveshare-s3-rlcd-4.2/`）

- **400×300 RLCD 反射屏驱动**：SPI 40MHz、1-bit 帧缓冲（PSRAM）、RGB565→单色转换、对比度调节（`rlcd_driver.cc`）
- **板载外设驱动**：
  - SHTC3 温湿度传感器（I2C）
  - PCF85063 实时时钟（纽扣电池备份，断电保持走时）
  - SD 卡（SDMMC，挂载于 `/sdcard`，存放白噪音 MP3、电子书与照片）
  - ADC 电量检测（GPIO4）+ 锂电充电管理
  - ES8311/ES7210 音频编解码（沿用原项目）
- **按键交互**：双键多手势映射（单击/双击/长按 × 两键），详见上方「按键映射使用说明」

### 2. 全新 UI（LVGL 9，五页循环）

| 页面 | 内容 |
|---|---|
| 🌤 **天气页**（主页） | 时钟卡 248×128（大字时钟）；合并卡 130×128（星期/日期 + 城市/天气 + 备忘录 2 行轮播）；下排 **照片轮播**（`/sdcard/photos/*.png`，10 秒轮换，宽度随图片比例）+ **书目列表**（`/sdcard/books/*.txt`，6 秒轮播） |
| 🎵 **音乐页** | 唱片方卡 170×170、歌名/歌手、上/中/下三行歌词、进度条（y262）+ 时间、音量临时胶囊 |
| 🍅 **番茄钟页** | 状态「番茄钟 · 专注中/已暂停」、大号倒计时、进度条、设定信息 |
| 📖 **阅读页** | 无顶栏沉浸阅读，通栏正文卡 384×284，卡内首行书信息，约 23 字 × 11 行 |
| ℹ️ **系统信息页** | 白底信息卡：CPU 频率 / 运行时间 / SRAM / PSRAM / 电池 / WiFi |

- 顶栏：左上时间或温湿度、正中「小智」+ 三态状态图标、右上白底胶囊（WiFi + 电池 + 电量%）
- 低电量弹窗提示；**5 分钟无操作自动省电**（刷新频率 1s → 5s）
- 页面代码拆分：`weather_ui.cc` / `music_ui.cc` / `pomodoro_ui.cc` / `reader_ui.cc` / `system_ui.cc` / `data_update_task.cc`（后台数据刷新任务）

### 3. 新增功能

- **电子书阅读器（TXT）**：SD 卡 `/sdcard/books/*.txt`，自动识别 UTF-8/GBK（GBK 转码缓存）、
  章节索引、按屏分页、阅读进度 NVS 持久化、按键翻页/切章，详见
  [电子书阅读器计划](docs/2026-09-25-电子书阅读器计划.md)
- **照片轮播**：SD 卡 `/sdcard/photos/` 存放 PNG（建议高度预转 122px），主页左下自动轮播
- **番茄钟**：启动/暂停/恢复/停止，可联动 SD 卡白噪音（MP3）伴听
- **白噪音播放器**：修复原框架播放卡顿，SD 卡文件扫描与管理（`managers/sdcard_manager`、`pomodoro_manager`）
- **备忘录**：新增/列表/完成/清空，NVS 持久化，天气页合并卡内 2 行轮播显示
- **天气回写**：由 AI 通过 MCP 工具写入天气数据，避免设备端频繁抓取
- **音量按键调节**：音乐页 USER 双击/长按 ±10%，即时生效并持久化
- **自动省电模式**：空闲降频刷新 + 活动检测唤醒

### 4. 新增 MCP 工具（语音可控）

| 工具 | 作用 |
|---|---|
| `self.disp.switch` | 语音切换页面（`toggle`/`weather`/`music`/`pomodoro`/`reader`/`system`） |
| `self.pomodoro.start/stop/pause/status` | 番茄钟控制（含白噪音开关、分钟数参数） |
| `self.memo.add/list/done/clear` | 备忘录增删查改 |
| `self.weather.update` | AI 回写天气数据 |
| `self.audio_speaker.set_volume` | 设置音量（与按键调节等效） |
| `self.disp.network` | 重新配网 |
| `self.system.info` | 查询 CPU/内存/运行时等系统信息（语音播报；屏幕查看见系统信息页） |

## 编译与烧录

### 环境要求

- **ESP-IDF v5.5.2**（组件清单要求 ≥5.5.2）
- Python 3.10+（3.14 已验证可用）

```bash
# 1. 进入项目
cd xiaozhi-esp32

# 2. 加载 ESP-IDF 环境
source ~/esp/esp-idf/export.sh     # 路径按实际安装位置

# 3. 首次配置：选择开发板
idf.py set-target esp32s3
idf.py menuconfig                  # 选择 Board Type → Waveshare S3 RLCD 4.2

# 4. 编译
idf.py build

# 5. 烧录 + 串口监视
idf.py flash monitor
```

常用命令：`idf.py erase-flash`（清 NVS 重置配网）、`idf.py menuconfig`（配置）。

### SD 卡文件约定

| 路径 | 用途 |
|---|---|
| `/sdcard/books/*.txt` | 电子书（UTF-8 / GBK 均可，GBK 自动转码缓存） |
| `/sdcard/photos/*.png` | 主页照片轮播（建议高度预转 122px，宽度自适应） |
| `/sdcard/white-noise/*.mp3` | 白噪音（番茄钟伴听） |
