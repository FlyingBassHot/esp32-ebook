# 电子书阅读器功能计划（TXT 版）

> 日期：2026-09-25
> 状态：设计完成，待开发（依赖板卡到货 + ESP-IDF 环境就绪）
> 已确认决策：**仅 TXT 格式 / MCP + AI 控制联网取书 / 阅读模式改键位**

## 1. 背景与目标

在本固件（微雪 ESP32-S3-RLCD-4.2，400×300 单色反射屏）上增加电子书阅读器：

- 本地：读取 SD 卡 `/sdcard/books/*.txt` 小说
- 联网：通过 MCP 工具让 AI 下载书籍到 SD 卡并打开
- 阅读体验：约 18 行 × 23 字 ≈ **400 字/页**，按键翻页，进度持久化

## 2. 可行性结论

**可行，中等工作量（估 1000~1500 行新代码）。TXT 阅读器无硬瓶颈，
翻页流畅度受 RLCD 全帧刷新机制制约，需配套一处驱动优化。**

### 有利条件（基础设施已齐）

| 需求 | 现状 | 位置 |
|---|---|---|
| 存储 | SD 卡已挂载 FAT `/sdcard`，有 `listFiles()` 接口 | `managers/sdcard_manager.h` |
| 联网取书 | `esp_http_client` 已在天气模块使用，可复用流式下载 | `managers/weather_manager.cc` |
| 内存 | 8MB PSRAM（OCT/80MHz）已启用 | `sdkconfig.defaults.esp32s3` |
| 中文字体 | `font_puhui_16_4`（7415 常用汉字，组件 `78/xiaozhi-fonts`） | `main/idf_component.yml` |
| 页面框架 | `DisplayMode` 枚举 + `CycleDisplayMode` + MCP 切页工具 | `custom_lcd_display.h` |
| Flash | 16MB 双 OTA + 6MB assets，书放 SD 无需改分区 | `partitions/v2/16m.csv` |

## 3. 技术方案（分三期）

### 阶段 1 — 本地 TXT 阅读器（核心）

- `reader_ui.cc`：复用天气页卡片风格——正文白底卡片 + 顶部章节名/进度 + 底部 AI 状态卡
- `reader_manager.cc`：
  - 扫描 `/sdcard/books/*.txt`
  - 编码检测（UTF-8 / GBK）+ GBK→UTF-8 按章节转码
  - 章节索引：扫描一遍"第X章"模式建立索引
  - **手动分页**：每页一个 `lv_label`（约 400 字符），不做整本滚动
  - 只在 PSRAM 保留 64~128KB 缓冲，按章节流式读取（整本书 2~10MB 不可整载）
  - 阅读进度存 NVS

### 阶段 2 — 联网取书（MCP + AI）

- `self.book.list` / `self.book.open(title)` / `self.book.page(next|prev)` / `self.book.chapter(n)`
- `self.book.download(url, filename)`：HTTP 事件回调分块写 SD（参照 `weather_manager` 模式），内存零压力
- AI 场景："帮我下载《XX》并打开"、朗读/点评当前页

### 阶段 3（可选后置）— EPUB

- 需 zlib 解压（IDF 自带）+ HTML 标签剥离，工作量翻倍
- **PDF 不做**（渲染引擎过重）

## 4. 新增 / 修改文件

### 新增（`main/boards/waveshare-s3-rlcd-4.2/`）

| 文件 | 职责 | 预估 |
|---|---|---|
| `reader_manager.h/cc` | 书库扫描、编码转码、章节索引、分页、进度 | ~500 行 |
| `reader_ui.cc` | `SetupReaderUI()` 阅读页布局 | ~350 行 |

### 修改

1. `custom_lcd_display.h/cc`：`DisplayMode` 加 `MODE_READER`；
   `SetupReaderUI` 声明、`ApplyDisplayMode` 分支；
   新增 `ReaderNextPage/ReaderPrevPage/ReaderNextChapter/ReaderOpenBook`；
   覆写 `SetChatMessage/SetEmotion` 适配阅读页 AI 卡
2. `waveshare-s3-rlcd-4.2.cc`：
   - **改键**：`IsReaderMode()` 时 USER 单击=下一页、双击=上一章、长按=下一章；
     BOOT 保持对话开关；非阅读模式行为不变
   - 注册 `self.book.*` MCP 工具（照 `self.pomodoro.*` 模式）
3. `rlcd_driver.cc`：**驱动级优化（性能关键，放里程碑 1）**
   - `RLCD_Display()` 当前无条件全帧推送 15KB → 增加按脏行范围的部分刷新重载
   - `Lvgl_flush_cb` 记录脏区并调用之；逐像素转换改为按行批量处理
4. `data_update_task.cc`：阅读模式刷新顶部时间/进度；章节转码放独立低优先级任务
5. 构造函数创建第 4 个页面

## 5. 性能瓶颈与对策

| # | 瓶颈 | 对策 / 预期 |
|---|---|---|
| 1 | **RLCD 刷新**：`Lvgl_flush_cb` 逐像素 RGB565→1bit（12 万次/帧）+ `RLCD_Display()` 无条件全帧推送 | 记录脏区只发片段（0x2A/0x2B 窗口命令支持改起止地址）+ 按行批量转换；预期翻页 150~300ms（液晶响应为物理下限） |
| 2 | **LVGL 大文本布局**：整本 label 测量 O(字符数) 会卡 | 按页渲染（每页 ~400 字符），O(1 页) |
| 3 | **GBK 转码**：几 MB 全转秒级停顿 | 只转当前章节、异步执行（复用后台任务模式） |
| 4 | **内存**：内部 RAM 紧张（音频/WiFi 争抢） | 书缓冲、HTTP/TLS 全走 `MALLOC_CAP_SPIRAM`；mbedtls 内容缓冲调小 |
| 5 | **CPU 争抢**：LVGL 任务优先级仅 2 | 下载用低优先级任务，避免与翻页抢核 |
| 6 | SD 带宽（单线 SDMMC ~2-4MB/s） | 读文本绰绰有余，**非瓶颈** |

## 6. 风险与真机验证点

1. **RLCD 部分窗口刷新是否残影** — 首个里程碑真机验证，不行则保留全帧回退开关
2. **GBK 生僻字覆盖** — 先支持 GB18030 常见区段，日志记录未映射字符
3. **模式记忆** — 阅读模式改键后易忘当前状态，MCP `self.disp.switch` 随时可退出

## 7. 里程碑

1. **驱动优化 + 空页面**：脏区刷新 + `MODE_READER` 空壳挂进切页循环，真机确认翻页速度与残影
2. **本地 TXT 阅读**：reader_manager + reader_ui + 键位翻页/章节跳转，进度存 NVS
3. **MCP 工具 + 下载**：`self.book.*` 工具组，URL→SD 流式下载，语音开书/翻页
4. （后置）EPUB、字号调节、AI 朗读当前页

## 8. 环境准备（开发机：Omarchy/Arch）

```bash
# 系统依赖
sudo pacman -S --needed cmake ninja gperf ccache dfu-util libusb

# ESP-IDF v5.5.2（工具链只装 esp32s3）
mkdir -p ~/esp && cd ~/esp
git clone -b v5.5.2 --recursive https://github.com/espressif/esp-idf.git
cd esp-idf && ./install.sh esp32s3

# 编译烧录
cd xiaozhi-esp32
source ~/esp/esp-idf/export.sh
idf.py set-target esp32s3
idf.py menuconfig    # Board Type → Waveshare S3 RLCD 4.2（默认值不是本板，必须改）
idf.py build
idf.py flash monitor # S3 原生 USB，串口通常 /dev/ttyACM0
```

注意：首次编译需下载工具链（1~2GB）与 60 个 IDF 组件，保持网络稳定。
